# /new-topic — 新增一個故事

主題：$ARGUMENTS

這個指令讓 wiki 長出一個新的故事頁。全部照 CLAUDE.md 的規則做；以下是順序與「做完」的標準。

## 1. 先了解現況
- 讀 `CLAUDE.md`（全部）、`wiki/index.md`、`wiki/overview.md`。
- 確認這個主題還沒有故事頁；如果和既有主題重疊很多，改成擴充既有主題頁，並告訴使用者原因。
- 決定 `id`（`t-英文關鍵字`）、`category`（只能用 CLAUDE.md 第 4.1 節列出的六種）、時期。

## 2. 找資料（目標：至少 4 份資料，其中至少 2 份讀到全文、至少 2 份直接談臺灣；特殊情況見 CLAUDE.md 4.4）
- 依 CLAUDE.md 6.1 的「全文去哪裡找」順序：開放取用的期刊官網 → 機構典藏 → 台大訂閱的資料庫（需台大網路或 VPN；只能少量、慢速，每次下載間隔 5 秒以上）。
- 需要用瀏覽器點按鈕才能下載的（例如華藝），列出清單請使用者處理，或請主 session 處理；**不可以破解驗證碼或繞過登入**。
- 資料多時可以派較便宜的模型平行蒐集，但每個 agent 只負責 2–4 份、只能改自己的資料卡與 `raw/`。

## 3. 每份資料
照 `/ingest` 的步驟 3–5：歸檔到 `raw/` → 全文筆記 `raw/notes/<id>.md`（附頁碼）→ 資料卡 `wiki/sources/<id>.md`。

## 4. 寫故事頁
- 複製 `templates/topic.md` 到 `wiki/topics/<id>.md`，標題照「主標：副標」格式（第 8.1 節）。
- 「故事是這樣的」4–6 段、每段 3–5 句，有人、有場景、有數字，每段都有 `[[s-...]]` 出處（盡量附頁碼）。語氣照第 8 節：寫給沒學過臺灣史的人。
- 「研究者怎麼看」寫出研究者之間的共識與分歧。
- 「還不知道的事」列出缺口。

## 4.5 頁首插圖（選做）
- 照 `templates/illustration-prompt.md` 生成一張木刻版畫風插圖（需要能操作瀏覽器使用圖像生成工具；不能的話，把填好的提示詞寫在回報裡，請使用者或主 session 生成）。
- 存檔與 frontmatter 照 CLAUDE.md 8.2。

## 5. 接上整個網站
- `data/timeline.json` 至少 3 個事件、`data/places.json` 有地點就加、`data/stats.json` 有可畫的數字就加（照第 5 節格式，註明算法）、有分歧就加 `data/debates.json`。
- 在至少 2 個相關的既有頁面加上 `[[新主題 id]]` 連結，並更新 `wiki/overview.md`。
- 出現兩頁以上會提到的機構、法令、人物，建名詞頁。

## 6. 檢查與記錄
- `python3 tools/build.py && python3 tools/lint.py`，錯誤修到 0，孤兒頁也要處理。
- `wiki/log.md` 加一筆 `## [日期] ingest | 新主題：<主題名>`，列出新增的資料卡、頁面、圖表與資料缺口。

## 做完的標準
新故事出現在首頁的配給券目錄、時間軸有它的事件、它的頁面 lint 0 錯誤，而且每一句事實都有出處。最後用白話回報：讀了哪些資料（全文幾份）、故事頁寫了什麼、還缺什麼。
